# Language in Culture and Responsible NLP — Project 2

**Editorial gatekeeping in historical isiXhosa newspapers (1884–1888):**
a controlled comparison of the missionary-backed *Isigidimi sama-Xosa*
against J.T. Jabavu's independent *Imvo Zabantsundu*.

> **Research question.** Does editorial control show up in the lexical data?
> We measure per-page **political-term density** in 19th-century isiXhosa
> using a hand-built, theme-organised political lexicon, and compare the
> two newspapers with a full stack of robustness controls (OCR noise,
> document length, era drift, language purity). We also examine recurring lexical
> themes with NMF topic modelling and test how reliably a TF-IDF + Logistic
> Regression classifier distinguishes the two newspaper sources. These
> analyses identify associations, **not causal evidence of editorial intent**

```bash
# 1. Verify corpus integrity (read-only)
python -m scripts.check_data

# 2. Build issue-disjoint Train/Val/Test splits (writes results/splits/*.csv)
python -m src.data.loader \
  --xh-dir data/XhTxt \
  --en-dir data/EnTxt \
  --metadata data/LanguageSplitTracker70-94.csv \
  --out-dir results/splits

# 3. Score political density + run robustness controls
python -m src.interpret.political_scorer \
  --manifests results/splits/train_manifest.csv \
              results/splits/val_manifest.csv \
              results/splits/test_manifest.csv \
  --lexicon config/political_lexicon.yaml \
  --text-root data \
  --results-dir results
```

## Reproduce Person 2's modelling and robustness experiments

**Prerequisite:** Generate the three issue-disjoint manifests in
`results/splits/` using Person 1's loader above. Neither model needs the
political-scorer results to run.

### A. NMF topic modelling

```bash
# Reproduce the selected eight-topic experimental stopword variant
python -m src.models.topic_model --topics 8
```

The script uses isiXhosa pages with `xh_pct >= 90` and `n_words >= 200`,
from **1884-01-01 through 1888-12-31**. For this run, the eligible pages were:

| Split | Pages | Issues |
|---|---:|---:|
| Train | 462 | 172 |
| Validation | 97 | 37 |
| Test | 141 | 50 |
| **Total** | **700** | **259** |

TF-IDF is fitted **on training pages only**, capped at 20,000 terms. The NMF
model is fitted on training pages; validation reconstruction error and top-word
diversity are reported. The final exploratory eight-topic variant uses a short,
**experimental** stopword list; it is not a linguistically validated isiXhosa
stopword inventory. To compare candidate counts, run:

```bash
python -m src.models.topic_model --topics 5,8,10,12,15
```

**Note:** The code automatically chooses the *smallest* model within 3% of the
lowest validation reconstruction error among the topic counts passed. Therefore
`--topics 5,8,10,12,15` may select five topics rather than eight. Use
`--topics 8` to reproduce the reported eight-topic variant. The model is
interpreted manually using its most prominent words and representative pages.

### B. Newspaper-source classification

```bash
# Validation-only hyperparameter selection (default: no test evaluation)
python -m src.models.newspaper_classifier --strict-overlap

# Final held-out issue-level evaluation, after model selection is frozen
python -m src.models.newspaper_classifier --strict-overlap --evaluate-test
```

The classifier uses the **shared observed date range, 1884-11-03 through
1888-12-01**, with the same isiXhosa purity and document-length filters as
above. The strict-overlap eligible sample was:

| Split | Pages | Issues |
|---|---:|---:|
| Train | 407 | 159 |
| Validation | 81 | 34 |
| Test | 105 | 42 |
| **Total** | **593** | **235** |

The implementation trains TF-IDF + Logistic Regression models, compares unigram
and unigram/bigram settings and `C` values of 0.1, 1 and 10 on **validation
issues**, and averages page-level predicted ISIG probabilities within each
issue. Training sample weights balance issues and newspaper sources. The final
selected configuration is **TF-IDF unigrams, `C=0.1`**, with source-name masking
enabled.

The expanded source-name sensitivity variant masks the tokens `imvo`,
`zabantsundu`, `isigidimi`, `sigidimi`, `xosa`, `samaxosa`, and `lamaxosa`.
This is **not complete boilerplate removal**: some masked forms may also have
legitimate uses in historical isiXhosa. A `--no-mask-source` option is available
as an ablation. The summary file records whether masking was used but does not
record the exact term list; retain the corresponding source-code version for
reproducibility.

### C. Page-position and OCR controls

```bash
# Compare the same validation issues using all eligible pages versus pages 3-4
python -m src.models.page_control

# Train an OCR-proxy-only baseline (mean word length + non-alpha ratio)
python -m src.models.ocr_control
```

Both controls use validation data and the same strict overlap, feature masking
and selected classifier settings. The page-position script **does not retrain**
separate page-specific models; it evaluates the existing model on restricted
validation documents. The two OCR features are crude proxies, not a complete
characterisation of OCR quality.

### D. Main Person 2 findings

| Experiment | Result | Reading |
|---|---|---|
| NMF (8 topics, experimental stopwords) | Validation relative reconstruction error **0.9149**; top-10 topic diversity **0.975** | Commercial advertising, civic/news vocabulary and source-associated prose emerged; labels remain interpretive |
| Classifier validation | **Macro-F1 1.000**, balanced accuracy **1.000** on 34 issues | All 29 IMVO and five ISIG validation issues classified correctly |
| Classifier held-out test | **Macro-F1 0.9545**, balanced accuracy **0.9861** on 42 issues | Confusion matrix `[[35, 1], [0, 6]]` (rows: actual IMVO, ISIG; columns: predicted IMVO, ISIG) |
| Expanded source-name masking | Validation macro-F1 **1.000** | Perfect validation performance persisted after masking additional title-related words |
| Page-position control | Macro-F1 **1.000** using all eligible pages from 14 matched validation issues; **0.925** using only pages 3–4 | One IMVO issue was misclassified on pages 3–4 |
| OCR-proxy-only baseline | Macro-F1 **0.452**; balanced accuracy **0.493** | These two simple surface features alone were poor newspaper predictors |

The NMF analysis showed a substantial **page-position effect**: a civic/news
NMF topic was prominent on IMVO page 2, and its issue-level average changed
when page 2 was removed. A source-associated topic was especially prominent
in ISIG. Those patterns warn against treating topics as direct measures of
political intent.

The held-out classifier's only error was `IMVO_1888-04-25` (page 2 was its
only eligible page), classified as ISIG with predicted probability
`0.5002413484151511`, just above the 0.5 threshold. This is post-hoc error
analysis, **not a reason to retune against the test set**.

**Interpretation limit:** The classifier demonstrates strongly distinguishable
lexical distributions. Neither its performance nor the NMF topics establish
that editorial control *caused* the differences. Page composition, recurring
publisher-specific text, institutional vocabulary, historical spelling and
OCR artefacts remain potential confounders. The two modelling pipelines have
different **date windows** and thus different sample sizes; do not present
them as evaluating exactly the same subset of pages.

## Cleaning decisions (for the Method section)

The corpus required three cleaning steps before modelling:

1. **Drop empty files** — 1,061 one-sided empties (isiXhosa pages with a
   0-byte stub in `EnTxt/` and vice versa — artefacts of the language-split)
   plus 1 truly blank page. No content is lost; the content lives in the
   sibling directory.
2. **Join page-level metadata** — `LanguageSplitTracker70-94.csv` is keyed
   by filename (`IMVO_1884-11-03_p001.txt`), not by issue ID. All 6,153
   retained documents matched exactly (100.0% coverage).
3. **Filter for analysis**:
   - `language == "xh"` (the lexicon is isiXhosa-only)
   - `xh_pct >= 90` (exclude mixed-language pages where English political
     vocabulary would be invisible to the lexicon)
   - `n_tokens >= 200` (length floor; below this, density is unstable)

## Robustness controls (what they test, what they found)

| Control | Test | Result (final, filtered) | Reading |
|---|---|---|---|
| OCR (word length) | Spearman ρ between score and mean token length | **0.30** | Structural: isiXhosa political vocabulary is polysyllabic. Not an artefact — documented, not eliminated. |
| OCR (non-alpha ratio) | Spearman ρ between score and non-letter character ratio | **−0.36** | Structural: political content concentrates in clean prose pages, not in noisy tables. |
| Era | Spearman ρ between score and year | **−0.22** | Mild temporal trend; reported, not controlled-out. |
| Length | Spearman ρ between score and `n_words` | **0.05** | Clean — log-odds metric is length-invariant. |
| Language purity | Spearman ρ between score and `xh_pct` | **0.14** | Weak after `xh_pct >= 90` filter; residual 0.14 documented as a limitation. |
| **Source (IMVO vs ISIG)** | Mann–Whitney U on median log-odds | **U = 367,410, p = 1.5 × 10⁻⁵** | **Headline finding — see below.** |

## Headline result

After language-purity and length filtering (**n = 1,917 pages, 637 issues,
1884–1888 overlap**):

- **IMVO**: median political log-odds = **−0.058** (mean −0.087, std 0.313)
- **ISIG**: median political log-odds = **+0.006** (mean −0.028, std 0.397)
- Mann–Whitney U = **367,410**, **p = 1.48 × 10⁻⁵**

**Reading.** For the same isiXhosa token count, *Isigidimi* pages show
statistically higher political-term density than *Imvo* pages. The
qualitative sample corroborates this: sampled ISIG pages contain land-grant
tables, quit-rent records, and moral-governance commentary; sampled IMVO
pages contain front-page advertising, subscription notices, and commerce.

**Interpretation.** The missionary press
*lexically constructed* the isiXhosa political domain — the vocabulary of
government, land, and law — as part of its translation project. Jabavu's
independent, advertiser-funded paper produced a different **page
composition**: more commerce, more subscription notices, more community
news. The 0.06 log-odds gap reflects this editorial/compositional
difference, not a claim about intent or reader reception.

## Reproducibility notes for teammates

- **Do not** re-run `src.data.loader` with a different random seed unless
  you also regenerate all downstream files. The seed (`--seed 42`) is
  documented in the Method section.
- **Do not** edit `config/political_lexicon.yaml` without re-running the
  scorer **and** re-checking the controls CSV. The lexicon version is
  logged in the scoring header (currently `v0.2.0`, 116 terms, 7 themes).
- **Do not** commit `data/XhTxt/`, `data/EnTxt/`, or `venv/`. `.gitignore`
  is set up to prevent it; if you accidentally `git add` them, unstage with
  `git restore --staged <path>` before committing.
- The **manifests** in `results/splits/` are the reproducible hand-off
  point between the loader and the classifier/topic model
  and the scorer. If your `train_manifest.csv` has different
  `issue_id` values than the committed one, your corpus or your seed is
  different — stop and reconcile.
